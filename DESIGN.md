# DESIGN.md — Nabil Shaikh Portfolio

## Identity & Positioning
- **Primary Identity**: Full Stack Software Developer
- **Core Positioning**: SaaS Development, Production Web Applications, Backend Engineering, Business Logic, REST APIs, Database Architecture, Authentication & Authorization, AI / LLM Integration, Performance Engineering, Technical SEO, Deployment & Production Engineering
- **Tagline**: *"Building software that works beyond the interface."*

## Aesthetic Direction
- **Style**: Editorial + Engineering + Premium SaaS
- **Vibe**: High-end software architecture presentation, disciplined visual restraint, typographic hierarchy, technical grid layout.
- **Palette**:
  - Ink Black: `#0B0A0D`
  - Warm Ivory: `#F5F3EF`
  - Crisp White: `#FFFFFF`
  - Muted Charcoal: `#6F6A70`
  - Subtle Border: `#DDD8DC`
  - Primary Plum Accent: `#721C50`
  - Dark Plum Accent: `#48102F`
  - Soft Muted Lavender: `#B79AB1`

## Typography
- **Primary Sans**: `Inter`, system-ui, sans-serif
- **Editorial Serif**: `Instrument Serif`, `Georgia`, serif
- **Technical Monospace**: `JetBrains Mono`, `Fira Code`, monospace

## Design Tokens & Spatial Cadence
- Baseline grid: 4px / 8px / 16px / 24px / 32px / 48px / 64px / 96px / 128px
- Border Radii: `rounded-xs` (2px), `rounded-sm` (4px), `rounded-md` (8px), `rounded-lg` (12px), `rounded-xl` (16px)
- Hairlines: 1px solid `#DDD8DC` (Light) or `rgba(255,255,255,0.08)` (Dark)
- Shadows: Minimal, diffuse elevation shadows (`box-shadow: 0 4px 20px -2px rgba(11, 10, 13, 0.05)`)
